欢迎来到我的个人博客！这是我的第一篇文章。

## 关于这个博客

这里将记录我的学习笔记、技术分享和生活感悟。

## 如何写新文章

使用以下命令创建新文章：

```bash
hexo new "文章标题"
```

## 本地预览

```bash
hexo server
```

访问 http://localhost:4000/ 查看效果。

## 生成静态文件

```bash
hexo generate
```

生成的静态文件将存放在 `public` 目录中。
